# M0-T4 异步小样（业务 job → DSH runtime job）

- 卡号：M0-T4
- 主责：DSH
- 阶段：M0 证据阶段；不是完整渲染管线
- 建立：2026-11-04
- 状态：**通过（模拟重启）**；真实进程重启未做
- 依据：`03_给DSH_M0_主控包.md` §7；技术手册 §6、§10.3
- 依赖：M0-T3 最小接线成立（有条件通过）；DSH `0.2.1-rc.5`；jobs 服务

## 1. 目标

验证“业务 job → DSH runtime job → 进度/取消/回读/重启核对”的映射，不只验证脚本能跑。

## 2. 范围

**做**

- 一个业务 job 状态机：queued / running / verifying / succeeded / failed / cancelRequested / canceled / needsReconcile；
- 每个业务 job 一个 executionAttempt，映射一个 DSH runtime job；
- 成功、失败、取消、模拟重启四条路径；
- 进度、取消、输出回读、重启核对；
- 状态证据落盘。

**不做**

- 不做真实渲染管线、不发布半成品；
- 不做真实进程重启（只做 `simulate_restart`，已标注）；
- 不做多进程并发/断电恢复；
- 不改 DSH jobs 服务，不新增 job kind（使用已注册的 `bash`，label 标为 video demo）。

## 3. 实现

- 插件：`test/fixtures/M0-T4/plugin/`（`@local/video-m0t4-jobs` 0.1.0，Host-only）
- 工具：`video_job_start`、`video_job_status`、`video_job_cancel`、`video_job_read`、`video_job_simulate_restart`、`video_job_reconcile`
- 业务存储：`test/fixtures/M0-T4/data/business-jobs.json`
- DSH runtime job：`ctx.jobs.start({ kind:'bash', label:'video demo <bj>', owner, run })`
