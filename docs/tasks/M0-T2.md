## 8. 判定规则

1. 所有维度用 **满足 / 部分 / 不满足 / 未验证 / 阻断**，每项附证据路径；
2. 硬门为“阻断/不满足” → 淘汰；硬门“未验证” → 进入 M0-T3 前必须补证；
3. 两条都有真实证据 → 选一条最可行作 M0-T3 主路线，另一条只作备份；
4. 只有一条 → 另一条标“不足”，**不凑数**；
5. 都不成立 → 考虑自研薄层，但先记录缺口与复审条件，**不直接开写**；
6. DSH 至少对每条最终候选复跑一个关键命令，不能只看 Codex 结论；
7. `ADR-001-draft.md` 只写草案：背景、候选、证据、暂定选择、后果、未验证项、复审条件；最终在 M0-T5 定。
