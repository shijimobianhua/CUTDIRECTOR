## 1. 目标

用最小工程验证：**DSH 插件能加载；真实 Agent 工具能调用；最小 Client 面板与 Agent 读写同一个 `projectId/revision`；页面写入经共享提交入口；写入后有变化通知；最小 Skill 能被发现/加载。**

只证明接线，不证明完整剪辑能力。

## 3. 范围（窄口径）

**做**

1. 一个最小 DSH 插件/夹具工程，能加载；
2. 注册至少一个真实 Agent 工具（读项目 / 提交修改），调用适配器而非直写文件；
3. 一个最小 Client 面板：显示 `projectId`、`revision`、片段/字幕；修改经适配器提交；
4. 提交后适配器发事件，Client 收到并刷新；
5. Agent 读取最新 revision，能接着改；
6. 一个最小 `video-editing` Skill 能被发现并加载（来源/hash 记录）；
7. 用 A-01 或技术夹具跑一个媒体执行片段（可硬编码一个片段，但必须保留真实 Agent 工具调用与页面共同读写证据）。

**不做**

- 不做完整工作台、完整五份 Skill 正文；
- 不接真实 ASR、不做完整渲染管线；
- 不启动 FableCut MCP、不使用 FableCut 原生 UI 写工程；
- 不改 FableCut 原生源码（完整收敛留 M1）；
- 不启用第二条路线；
- 不把 A-01 的媒体可解码当作 AC-06 内容通过。
