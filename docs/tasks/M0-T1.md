### 6.1 每段素材记录模板

必须用实际探测结果填写，不能按扩展名猜。

```text
assetId:
原始路径:
sha256:
容器/编码:
时长:
分辨率:
帧率（有理数）:
音频:
旋转/像素比例:
时间原点/异常:
用途:
必须保留项:
```

字段规则：

- `assetId`：`A-01`、`A-02`、`A-03`，一旦分配不复用；
- `sha256`：对原始文件计算；文件变动必须重新登记，不能覆盖旧记录；
- `帧率（有理数）`：例如 `30000/1001`，不写 `29.97`；
- `音频`：有无、采样率、声道、是否静音；
- `时间原点/异常`：非零起点、VFR、可变帧时长、旋转元数据、缺音轨等；
- `必须保留项`：由用户确认，不由 DSH 猜。

### 7.1 T-A 口播 / 产品讲解

- 目标：从较长口播中做出约 1 分钟版本；
- 必须保留：产品名、参数/数字、否定表达、条件与限制说明；
- 预期保护区域：含上述内容的句子及其上下文，不允许为时长删除或改写语义；
- 验证方式：逐项核对成片与字幕；选段可回查来源区间；时长偏差在“允许偏差”内；
- 人工检查：语义是否完整、否定是否被削弱、限制说明是否还在。

### 7.2 T-B 教程 / 产品操作

- 目标：保留关键步骤与结果，形成可看懂的教程片段；
- 必须保留：步骤顺序、操作结果、必要讲解；
- 预期保护区域：关键操作画面与其对应讲解，不允许只剩讲解没有操作；
- 验证方式：步骤清单逐项对照成片；缺失步骤明确报告；画面与讲解对应可回查；
- 人工检查：步骤是否可跟随、结果是否可见、是否误导。

### 7.3 T-C 媒体边界

- 目标：对所选边界条件给出“支持 / 明确拒绝”的结论与理由；
- 必须保留：时间原点、旋转、音轨映射的可核对记录；
- 验证方式：`ffprobe` 原始记录；若有转换，保留原素材、工作媒体与转换参数；拒绝时检查是否明确报错而非静默错误；
- 人工检查：结论是否与探测一致，是否把“未验证”写成“支持”。
