# V2 用户态界面：Codex 执行书

## 0. 最终形态（用户最新要求）

打开 **Video-agent** 后，**整个主区域变成视频应用**，不是永久左聊天/右工作台的二分屏。

- 默认看到应用自己的左侧导航 + 内容区（概览/视频/字幕/导出）；
- Agent 聊天是应用内的一个入口：点“和 Agent 对话”打开右侧/底部抽屉或弹层；
- 抽屉里是真实 DSH 原生 conversation factory，不是假聊天；
- 关掉抽屉后，应用全宽显示视频；
- 不再把聊天和工作台各占 50% 常驻。


- 日期：2026-11-04
- 目标：把“工程师控制台”改成“普通人能用的 Agent 视频工具”
- 执行：Codex；DSH 验收
- 分支：`m1-m3-first`
- 不做：再加技术面板/字段；不改 profile

## 1. 用户只需要三件事

```text
1. 上传视频
2. 对 Agent 说想怎么剪
3. 看结果 / 导出
```

默认界面必须围绕这三件事，不是围绕 projectId/revision/command/SRT/provider。

## 2. 默认页面

```text
┌─────────────────────────────────────────────┐
│ 视频工作台        [上传视频] [导出]          │
├──────────────────────┬──────────────────────┤
│                      │ 和 Agent 聊天         │
│      大播放器         │ “把开头剪掉两秒”      │
│                      │ “加中文字幕”          │
│                      │ “导出 1080p”          │
├──────────────────────┴──────────────────────┤
│ 视频片段（缩略图 + 时长） / 字幕文本（可读）   │
└─────────────────────────────────────────────┘
```

- 上传：文件选择/拖拽，自动建工程；不要求路径、projectId、格式；
- 播放器：大、优先；
- 聊天：真实 DSH Agent，输入框显眼；
- 片段：缩略图/时长，不显示 assetId/inFrame/outFrame；
- 字幕：直接显示中文文本，可改；不显示 SRT/transcript/provider；
- 导出：一个按钮，进度用普通人语言；
- 高级：默认隐藏，只有“高级/调试”抽屉里才出现 revision、JSON、命令历史。

## 3. 必须隐藏/改写

不要出现在默认 UI：

```text
projectId / baseRevision / commandId / assetId / inFrame / outFrame
SRT / transcript / provider / manifest / hash / JSON
H.264 / working media / normalize / MediaMissing
```

改成：

```text
工程 -> 视频
revision -> 版本
片段 -> 片段
导出 -> 导出视频
SRT -> 字幕
ASR provider -> 语音识别
渲染任务 -> 导出进度
冲突 -> 视频已被修改，请先刷新
```

## 4. Agent 负责翻译

用户说人话：

```text
把开头剪掉两秒
把中间停顿去掉
加中文字幕
导出竖屏
```

Agent 自己调用工具；UI 只显示结果和一句人话状态。

## 5. 验收

- 不懂视频格式的人，能在 30 秒内上传 A-01 并看到播放；
- 能直接对 Agent 说一句剪辑指令，不接触任何技术字段；
- 能点“导出”拿到 MP4；
- 技术信息只在“高级”里；
- 聊天区不能空白；如果自定义 main 页聊天仍不能稳定显示，切稳定形态（DSH 原生聊天主页面 + 工作台右侧面板），但必须明确报告；
- 现有 24/24、UI/SRT/ASR 测试保持；
- 只在 test-video 测试，不装 desktop。

## 6. 视觉

- 参考“CUTDIRECTOR”和用户给的归藏设计：暖纸底、黑字、朱红强调、留白、卡片、清晰层级；
- 不堆按钮；主操作不超过 3 个；
- 手机/窄栏不横向溢出。
