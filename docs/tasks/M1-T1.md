# M1-T1 项目服务与适配器产品化

- 卡号：M1-T1（骨架，不是完整实现计划）
- 主责：DSH；支援：Codex（冻结接口后做边界实现/测试）
- 阶段：M1 首卡；A-01 FFmpeg smoke 已过，面板按钮仍待确认
- 建立：2026-11-04
- 状态：**未开工（内部服务可开始）**
- 依据：[ADR-001](../adr/ADR-001-主编辑底座.md)、[ADR-004](../adr/ADR-004-DSH版本与接线.md)、[ADR-005](../adr/ADR-005-存储与原子提交计划.md)

## 1. 目标

把 M0 的适配器 spike 变成可复用的项目服务：一个权威 writer、稳定 projectId/revision、commandId 幂等、事件、项目切换/历史/重开的契约；不改 FableCut 原生源码。

## 2. 依赖

- M0-T5 条件 1：面板按钮点击确认（否则 M1 只能做内部服务，不宣称 UI 可用）；
- M0-T5 条件 2：A-01 预览/导出 smoke **已过**（[M0-T5 导出 Smoke](../handoffs/M0-T5_导出Smoke.md)）；FableCut 原生/完整工程导出仍未做；
- A-01 素材；FFmpeg 4.4.1/ffprobe 3.4.2；
- DSH 0.2.1-rc.5。

## 3. 范围

**做**

1. `src/core` 的 ProjectStore/Command/Revision/Event 接口；
2. `src/adapters` 的 FableCut HTTP/JSON 适配器（复用 spike 契约）；
3. 项目切换/新建/删除/历史恢复的最小映射；
4. 适配器账本持久化、原子写、崩溃恢复测试；
5. 单元/集成测试：并发、旧基准、幂等、重开、事件；
6. 把 M0 夹具工程迁移到 M1 测试目录。

**不做**

- 不改 FableCut 原生源码；不收敛其 26 个写入口（另开 M1 任务）；
- 不做完整工作台/播放器（M1-T2）；
- 不接真实 ASR、不做完整渲染管线；
- 不把 spike 直接当产品代码复制，先抽契约。

## 4. 验收

- [ ] ProjectStore 接口有类型/契约文档；
- [ ] 同一 projectId 的 revision 单调、旧基准拒绝、同 commandId 同内容重放；
- [ ] 两个并发写者最多一个成功；
- [ ] 项目切换/重开/历史恢复有测试；
- [ ] 进程被杀后账本/工程可核对，不重复启动；
- [ ] 适配器不直接写 `project.json` 以外的第二份权威时间线；
- [ ] 测试命令与日志落盘。

## 5. 人工检查

- 项目切换后 Agent/页面是否看到同一 projectId/revision；
- 恢复是否生成新 revision，不覆盖旧版本；
- 失败信息是否能指导用户继续，不是静默失败。

## 6. 交接

- 完成后交给 M1-T2 接页面/播放器；
- 未解：FableCut 原生写入口收敛、HEVC/导出、字幕映射；
- 不进入 M1-T2 前的门槛：本卡测试 + A-01 预览 smoke。
