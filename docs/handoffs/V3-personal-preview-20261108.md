# CUTDIRECTOR V3 个人试用交付与待实测

更新日期：2026-11-08。当前交付是 **0.3.0-preview.2 个人试用版**。它已经切换到当前用户 DSH Desktop 的 desktop profile，后台已加载 schema 32。此文区分已实现、跳过实测与尚未接通，不将它们统一写成通过。

## 怎么开始

1. 打开 DSH Desktop，从侧栏进入 CUTDIRECTOR 视频制作。
2. 首页可以选择“我有素材”“从想法开始”，也可以先“创建一个可练习的示例”。示例只生成本机文字分镜，不出图、不调用模型。
3. 文字助手优先使用 DSH 已配置的模型。没有模型时仍能记灵感、导入素材、安排片段和手工保存分镜；具体模型建议需要在 DSH 设置中连接模型。
4. 上传参考视频或图片后，可以到“检查画面”准备模型检查。先本机准备画面，再单独确认发送和费用。视频最多抽取8张，不代表检查完整声音和动作。
5. “交付成片”创建新的剪映草稿；在剪映精修和导出后，导入最终 MP4 归档。工程成片上限为25分钟。

当前安装没有代替你发起任何付费模型、图片、视频或搜索任务。试用时仍保留产品本来的上传和费用确认按钮。

## 本批已实现的补充

- 灵感有独立对话和新对话，不需要先建项目。可选择是否附上原始灵感和保存的补充。建议经确认存为补充，可撤销；旧建议不能覆盖后续手改。
- 灵感可直接收 PNG/JPEG 图片和 MP4/MOV 视频。附件可预览并返回，加入项目时明确选择“只作参考”或“用于视频内容”。不会自动发给模型。
- 口播证据可以在同一工程版本中连续分页读取，不能跳过未提供范围；读取过的证据才进入建议校验。长方案可以用连续句号区间表达。仍受单次循环预算和资料体积限制，不能承诺任意长素材一次处理完。
- 按用户填写的音乐速度安排换画面，先看方案，再放进未确认编排。保留字幕映射，校验区间和总时长。没有自动听音乐或自动加配乐；配乐仍在剪映添加对齐。
- 制作步骤支持分组、折叠、展开和模板保存，展示调整不使旧成果失效。人工完成当前素材检查后可显示对应步骤已有检查依据，模型建议不会替代人工批准。
- 工具中心可以发现真实安装的 DSH 扩展，读取清单、选择版本、检查、启停、升级和降级。项目内可准备并确认调用，保留来源及结果。文本建议不会自动修改工程。
- 提供实际 DSH 示例扩展：镜头节奏检查1.0和1.1版。它只分析本次附上的镜头时长，不联网、不调用模型。
- 模型看图检查接入 DSH 单次模型请求和真实图片附件接口。调用前检查模型声明支持图片输入，并再次核对开关与版本；记录源画面及发送的附件摘要。普通素材和“只作参考”的图片/视频都可准备检查。结果可带入自己的导演对话，用户再发送。
- 制作方法可从当前 DSH 方法目录读取用途，选择后才读正文，预览并确认保存本机快照。与文件/ZIP导入共用校验，不运行脚本，也不注入全局执行权限。
- 图片和视频均有原文件重连路径，校验内容摘要和媒体信息，保持已有ID与历史；不接受用另一份内容替代原文件。
- 新手练习项目、通俗错误引导、独立版本化沟通策略、历史上下文依据，以及离线固定样片评测工具已加入。
- 新增数据库迁移采用事务；后台退出停止自有分析和取帧进程；保留任务幂等、版本冲突及未知结果不自动重发的规则。

## 尚未接通的实现边界

这三项与“付费验证暂缓”不同，仍是功能缺口，因此不能把整份PRD宣告全部完成：

1. **Codex图片执行器**。已读取实际安装的 `@deepseek-ai/dsh-subagent-codex 0.2.1-rc.5`，它对外返回一次文字任务结果。原生Codex存在图像功能不等于该DSH插件提供图片产物回收。当前仍用内置图像接口或导入外部产物；没有伪装成Codex已完成出图。
2. **任意外接图片/视频工具的自动替换**。外接DSH协议已打通文字建议和参考分析；外部媒体产物回收、远端任务轮询及生成专用授权尚未统一。Seedream、Seedance、手工导入的现有专用路径继续可用。
3. **原生DSH/Codex/Claude Agent委派隔离**。没有因插件已安装就开放其工程写权限。隔离与产物契约未确认的角色保持不可用，CUTDIRECTOR自己的导演循环与内置制作能力继续工作。

界面图形步骤已经实现保存、依赖影响和阶段入口；它仍调用各阶段本来的审批流程。可用性不能解释为任意第三方Agent会自动获得工程或付款权限。
