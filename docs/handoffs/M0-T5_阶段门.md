## 2. 不能写成“已通过”的项

- **面板按钮实际点击/视觉**：DSH 未执行；slot active + panelGets 是运行证据，不等于用户点击/视觉验收。
- **真实进程重启**：M0-T4 只做 `simulate_restart`；真实 DSH 进程重启后的 job 核对未做。
- **A-01 FFmpeg smoke 已通过**：H.264 预览代理、5 秒导出、中文 SRT 烧录、ffprobe 核对；但 **FableCut 原生导出/完整工程导出未做**，不能把 smoke 当成完整导出。
- **HEVC 浏览器解码**：未验证；FableCut 服务能返回媒体，不代表浏览器能播。
- **FableCut 原生 UI/MCP 收敛**：26 个写入口未收敛；M0 只走适配器。
- **中文 ASR/字幕映射**：未接、未验证。

## 3. 决定

- **允许**把 M1-T1/T2 作为“卡骨架”交付与评审；
- **M1-T1** 现在可以做“项目服务/存储”内部实现（A-01 FFmpeg smoke 已过）；**不得宣称工作台/完整导出已可用**；
- **M1-T2/工作台** 仍需先满足：
  1. 用户手动点一次面板“加测试片段”，确认 `panelPuts` 增加、revision 更新；
  2. 完整工程导出/预览路径另做（FFmpeg 单素材 smoke 不能替代）。
- 若面板按钮未确认，M1 仍可做内部服务，但**不得宣称工作台/预览/导出已可用**。
