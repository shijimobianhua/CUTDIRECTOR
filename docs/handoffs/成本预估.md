# 成本预估（模型 token，不含人工）

- 日期：2026-11-04
- 用途：给“跑完 M0/M1/M2/M3”做预算，不是供应商报价
- 口径：模型输入/输出 token；不含人工审片、订阅费、商业素材、云服务
- 误差：±50%；M0 的 token 是估算，不是账单

## 1. 估算依据

按任务卡规模、当前 M0 实际消耗、以及“每张卡多轮上下文 + 返工 1.5 倍”估算：

| 阶段 | 输入 token | 输出 token | 说明 |
| --- | --- | --- | --- |
| M0（已完成，估算） | 15—25M | 1—2M | 本会话 + Codex 两轮 + WorkBuddy 两轮 |
| M1（项目服务/工作台/导出/Skill） | 20—30M | 1.5—2.5M | 约 8—12 张卡 |
| M2（真实任务/ASR/字幕/渲染） | 30—40M | 2—3M | 含真实素材反复跑 |
| M3（联合验收/回归/打包） | 15—25M | 1—2M | 回归与修缺陷 |
| **M1—M3 合计** | **65—95M** | **4.5—7.5M** | 未含 1.5 倍返工 |

含 1.5 倍返工：输入 100—140M，输出 7—11M。

## 5. 建议

1. **只做今天能验证的**：M0 收尾 + M1 最小项目服务/预览，约 ¥70—130（标准档）+ 你 1—2 小时审片。
2. **M1 完整**：约 1—2 周，¥170—260（标准档）+ 人工 8—15 小时。
3. **M1—M3 首版**：约 3—6 周，¥800—1,200（标准档）+ 人工 30—60 小时；高端模型 ¥2,900—4,400。
4. **不要今天硬做全量**：省不了多少钱，主要风险是证据/验收质量下降，后面返工更贵。

## 6. 省钱办法

- 用经济档做调研/文档/回归，标准档做关键实现；
- 减少多代理并行和重复读长文档；
- 每张卡先冻结契约，再让 Codex 实现，减少来回；
- 真实素材一次跑通再扩大，不反复全量重跑；
- 保留会话/证据，避免重复审计。
