# ADR-001 主编辑底座与工程事实来源

- 状态：**初定（M0-T5）**，允许复审
- 日期：2026-11-04
- 关联：[M0-T2 卡](../tasks/M0-T2.md)、[M0-T3 卡](../tasks/M0-T3.md)、[M0-T4 卡](../tasks/M0-T4.md)、[M0-T5 阶段门](../handoffs/M0-T5_阶段门.md)
- 草案历史：[ADR-001-draft.md](ADR-001-draft.md)

## 1. 背景

M0 需要回答：哪一个候选能成为 Video-agent 的权威编辑底座，或至少成为联合小样验证共同编辑的对象。约束：一份项目一个权威编辑服务；页面与 Agent 经同一写入口；不能维护两份可独立修改的时间线。

## 2. 证据

| 项 | 结果 |
| --- | --- |
| 候选 | FableCut `579b08e`（唯一进入小样；OpenChatCut 证据不足、Timeline Studio 不推荐） |
| 原生写入口 | Codex 第二轮列出 26 个（W01–W26）；HTTP/MCP/UI/历史/项目切换均可写，未收敛 |
| 原生预检 | 伪造高版本 200、`force=1` 200、缺字段 200、双 server 同 data dir 都能写 |
| 适配器窄口径 | `test/spikes/g0-1/writer-adapter.js`：并发一成一败、旧基准 409、同 commandId 同内容重放、异内容 409、force 400、单实例 |
| M0-T3 联合小样 | 插件加载、工具真实调用、面板读到 rev7、Agent 读 rev7、事件、Skill 加载；按钮点击人工未做 |
| M0-T4 异步小样 | 业务 job ↔ DSH runtime job：成功/失败/取消/模拟重启四条路径 |

## 3. 决定

**首版采用 FableCut 原生 `project.json` 作为工程文档，DSH 写入口适配器作为唯一 writer；FableCut 原生 UI/MCP 不参与权威写入。**

- 工程所有权：适配器拥有提交、baseRevision、commandId 幂等、事件；FableCut 只提供工程文档/操作语义/媒体服务。
- M0/M1 首个联合路径：适配器 + 最小 Client 面板 + Agent 工具；不启动 FableCut MCP，不用原生 UI 写工程。
- FableCut 原生 HTTP/MCP/UI 的完整收敛是 **M1 门槛任务**；未完成前不把“FableCut 原生 UI 可共同编辑”写成事实。
- 不采用 OpenChatCut 作为首版主路线；不启用自研薄层，除非 FableCut 适配器路线失败。

## 4. 后果

### 正面

- M0-T3/T4 已证明适配器可作为唯一写入口，M1 可以围绕它建项目服务/命令/任务。
- 不需要先自研完整时间线；FableCut 的工程/媒体语义可复用。
- 失败时有明确复审路径：先收敛原生写入口，再考虑换底座或自研。

### 代价与风险

- 适配器是新增的一层，必须与 FableCut 的工程语义同步；两套 schema 可能漂移。
- 适配器账本是 JSON，未做 fsync/崩溃恢复；工具层 commandLedger 是进程内。
- 只支持单项目 `P`；项目切换/历史/新建/删除未接。
- HEVC/VFR/旋转/分数帧率未在浏览器/导出验证。
- FableCut 原生 UI/MCP 仍可绕过适配器；M1 必须限制或收敛，否则不能给真实用户。
- 根 MIT 不覆盖字体/FFmpeg 构建/模型/素材；分发意图仍是“本机自用”。

## 5. 复审条件

1. 适配器无法在 M1 覆盖项目切换/历史/删除，或必须维护第二份权威时间线；
2. 原生 UI/MCP 收敛失败，且无法在 M1 限制为只读/禁用；
3. 真实素材预览/导出无法在 M1 首卡通过；
4. 字幕/时间映射导致 AC-02/AC-03 无法成立；
5. 许可证/分发条件变化。

## 6. 下一步

- M1-T1：把适配器/项目服务产品化，补项目切换、历史、原子写与恢复；
- M1 首卡门槛：真实 A-01 预览 + 导出 smoke；FableCut 原生写入口收敛计划；
- 本 ADR 在 M1 首卡完成后复审。
