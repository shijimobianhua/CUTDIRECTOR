# ADR-002 预览/导出与媒体归一化（路线）

- 状态：**初定路线；A-01 FFmpeg smoke 通过，完整工程/原生导出未验证**
- 日期：2026-11-04
- 关联：[M0-T4 证据](../handoffs/M0-T4_证据.md)、[M0-T5 导出 Smoke](../handoffs/M0-T5_导出Smoke.md)、[ADR-001](ADR-001-主编辑底座.md)

## 1. 背景

首版需要 MP4、UTF-8 SRT、可重开工程；字幕烧录路线未定；A-01 为 HEVC 640×1280 24fps 单声道；本机只有 FFmpeg 4.4.1 / ffprobe 3.4.2。

## 2. 决定（路线）

1. **探测/归一化**：`ffprobe` 记录容器/编码/时长/分辨率/有理数帧率/音频/旋转/原点；不支持的格式明确拒绝，不静默转码；需要工作媒体时保留原素材与转换参数。
2. **预览**：M1 先做最小播放器（HTML5 video）读取 FableCut `/media/*`；HEVC 若浏览器不支持，明确提示或生成 H.264 工作媒体，不静默失败。
3. **导出**：M1 先用 **FFmpeg 子进程**从工程快照导出 MP4（H.264/AAC）；字幕先外置 UTF-8 SRT，烧录字幕作为可选路线验证。
4. **版本绑定**：导出使用 `renderManifest`（projectId、revision、输入 hash、输出规格）；r1 渲染期间编辑到 r2，产物只归 r1。
5. **成片验证**：不只看退出码；实际解码、时长、分辨率、音频、字幕逐项检查；失败/半成品不发布。

## 3. 已验证与未验证

已通过（A-01 FFmpeg smoke）：
- H.264 360×720 预览代理，57.631s，AAC 单声道；
- 5 秒 H.264/AAC 导出片段；
- 中文 UTF-8 SRT 烧录，抽帧可见；
- ffprobe 独立核对时长/分辨率/音频。

未验证：
- FableCut 原生导出（需要浏览器/headless）未跑；
- 从完整工程 JSON 到成片的映射未实现；
- HEVC 浏览器解码未验证；预览代理是 H.264，不等于原素材可播；
- 字幕烧录/SRT 样式、字体、中文换行未验证（只有一条 smoke 字幕）；
- VFR/旋转/分数帧率/音画偏移未验证。

## 4. 后果

- M1 首卡必须先做“真实 A-01 预览 + 一个最小导出 smoke”，再谈完整导出；
- 如果 HTML5 不能解 HEVC，M1 必须显式生成 H.264 工作媒体，并记录“预览用工作媒体、导出用原素材/工作媒体”的选择；
- FFmpeg 4.4.1/ffprobe 3.4.2 较旧，AV1/HEVC 10-bit 可能不支持；升级需记录版本与原因。

## 5. 复审条件

1. 真实 A-01 无法预览或导出；
2. 字幕时间/中文换行不可接受；
3. r1/r2 产物归属无法保证；
4. 分发要求导致 FFmpeg 构建许可不可用。
