## 1. 背景

M0 需要回答：哪一个候选能成为 Video-agent 的权威编辑底座，或至少成为 M0-T3 用真实页面与 Agent 验证共同编辑的对象。

约束（来自总览 §3.1、技术手册 §2.1）：

- 一份项目只有一个权威编辑服务；
- 页面与 Agent 必须经同一写入口；
- 不能维护两份可独立修改的时间线；
- 原生编辑器已有写入口时，必须接入其事务、变化通知与版本机制。

## 3. 暂定选择

**FableCut 原生 `project.json` + 收敛后的唯一提交入口。**

但这不是“已选底座”，而是“唯一允许进入 M0-T3 前置门（G0）的路线”。在 G0 通过前，不得在 ADR 或任务卡中写成最终决定。

2026-11-04 更新：**G0-1 的窄口径已通过**——DSH 写入口适配器作为唯一 writer，`baseRevision`/`commandId` 幂等/拒绝 `force`/单实例/事件均实测通过；Codex 第二轮列出 26 个原生写入口，说明 FableCut 原生 HTTP/MCP/UI 的完整收敛仍未完成。因此 M0-T3 只按“适配器唯一 writer、FableCut HTTP 仅引擎、不启动 MCP、不使用原生 UI 写工程、单项目 `P`”的窄口径进行；原生收敛留 M1。

### 3.1 为什么是 FableCut

1. 本机 Windows + Node 24.18.0 可安装、可启动、可 HTTP 读写、可重开；
2. 同一 live `project.json` 是明确的权威文档，工程位置可定位；
3. `ProjectOps` 为浏览器/Node 共用的纯操作模块，具备收敛写入口的基础；
4. 根 MIT，字体有独立清单；无 npm 运行时依赖，验证成本低；
5. 片段、轨道、字幕文本片段、音频、历史、版本恢复均有源码或夹具证据。

### 3.2 为什么不是另外两条

- **OpenChatCut**：源码有统一 commands、提案基线、CAS/串行化、`wordRef` 等正面实现，但本轮没有安装/运行证据；AGPLv3 + Remotion 4.0.537 的复用/分发条件未决。不能凭源码功能数量升级为第二路线。
- **Timeline Studio**：完整源码未取得、无安装/运行；已审无头路径拒绝可见字幕、`Math.round` 取整 fps；CLI 另存 output.project，与打开页面的统一提交未证实。

## 4. 后果

### 4.1 正面

- 可用最小成本进入 M0-T3：真实页面、真实 Agent、同一 `projectId/revision`、变化通知都可围绕 FableCut 的 HTTP/MCP 面验证；
- 不需要先自研完整时间线，M0 能把精力放在“共同编辑”而不是重造编辑器；
- 失败时仍有明确的复审路径：先收敛写入口，再评估 OpenChatCut 或自研薄层。

### 4.2 代价与风险

- **两个写进程**：UI HTTP 与 MCP 各自读写 `project.json`，没有共享锁；`?force=1` 可绕过 revision 检查；
- **无 commandId 幂等账本**：同 ID 同内容重试、同 ID 异内容拒绝尚未成立；
- **字幕来源映射缺口**：caption 是 text clip + `wordTimes`，缺 segmentId/来源词/纠正实例链；
- **时间模型**：数值 fps（含 29.97 浮点），不是有理数 + 整数帧契约；
- **导出依赖 FFmpeg**：已装 4.4.1，但成片与 r1/r2 隔离未验证；
- **许可证/分发**：MIT 根许可证不覆盖字体、FFmpeg 构建、模型与素材，需逐项清单。

## 5. 未验证项

- DSH 插件加载、真实 Agent 工具调用、Client 面板、变化通知、Skill 发现；
- 页面与 MCP 并发写、崩溃恢复、旧基准竞争、commandId 幂等；
- 导出 MP4/SRT、实际解码、r1 渲染期间编辑到 r2 的版本归属；
- 30000/1001、VFR、旋转、非零原点、缺音轨、中文/空格路径；
- 中文字体与烧录字幕；
- 真实中文素材上的字幕纠正、重排、裁剪后映射。

## 6. 复审条件

出现以下任一情况，回到 ADR 复审，不继续扩建：

1. 无法把 HTTP + MCP 收敛为唯一提交入口，或必须维护第二份独立时间线；
2. 旧基准并发提交不能做到“最多一个成功”；
3. 人工改字幕后 Agent 接续会丢失纠正，或重排/裁剪后无法可靠映射；
4. 导出路线不可用，或无法证明 r1/r2 隔离；
5. 许可证/分发条件与用户意图冲突且无替代；
6. 在 M0-T3 的任何关键项（插件、工具、页面、通知、Skill）失败且无法在受控范围内修复。
