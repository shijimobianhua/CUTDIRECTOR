# ADR-003 中文 ASR 与对齐（验证计划）

- 状态：**计划，未选型**
- 日期：2026-11-04

## 1. 背景

首版需要一条真实可用的中文转写与时间依据；当前 M0 没有接 ASR，A-01 未转写；不能用画面猜保留项。

## 2. 计划

1. 候选：FunASR、WhisperX（备选）；只选一条首版路径，不并行接两套。
2. 契约：`transcript`（assetId、model、language、words[{text,start,end}]、精度/不确定项）；字幕纠正与原始转写分离。
3. 验证：A-01 与 A-02（待补）上检查中文、数字、否定、专名、时间精度、缺失覆盖、资源/耗时。
4. 失败处理：时间精度不足时明确降级为句级/片段级，不假装字级切词；无音轨/静音明确拒绝。

## 3. 未决

- 本机 Python 3.9 alpha 与 GPU/内存是否满足；
- 模型权重/许可/下载条件；
- 是否允许云端转写（默认不允许私有媒体出本机）。

## 4. 复审

M1 首卡不接真实 ASR；M2 前用 A-01/A-02 做一次真实对比后定。
