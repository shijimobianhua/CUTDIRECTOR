# 界面修整 r2
日期：2026-11-08。对应用户截图的修正，发布为0.3.0-preview.5。

## 行为调整
- 保存成功通知增加2.8秒自动关闭和手动关闭入口，新通知取消旧计时器；错误提示保持可关闭，避免被提前抹掉。
- 移除鼠标点击输入框时的厚焦点描边，Tab导航继续提供键盘焦点反馈。
- 删除无限画布、空间坐标、阻尼相机、缩放和固定底部工具条。灵感仅保留响应式整齐卡片网格，搜索和筛选保持输入焦点、支持中文输入法。
- 工作台改为制作首页：新建作品、继续制作、待办、最近灵感入口和模型准备状态。灵感库专门负责收集整理，两者不再重复。
- 输入、搜索、筛选与卡片回到正常文档流，修正小窗口拥挤；设置区块和聊天标题补充分隔与换行。
- 移除重复页面进入动画；快速导航取消旧过渡，路由切换重置旧滚动位置；隐藏卡片重新出现不再从零坐标飞入，已有动画不会无限叠加。
