# CUTDIRECTOR V3 扩展制作协议

更新：2026-11-08。唯一宿主是 DSH。CUTDIRECTOR 保持自己的会话、导演循环、工程写入及授权；外接工具负责一项明确的制作任务。兼容协议支持文字建议、参考分析、图片和视频生成。已有 Seedream、Seedance、剪映交付继续保留专用路径。

## 用户入口

设置 → 工具与能力 → 接入更多制作工具。工作台列出两个自带连接方式：Codex 原生出图、DSH 原生只读分析；也发现已安装 DSH 插件登记的兼容工具。点击“接入并检查”，固定版本并检查，成功后启用。新版本需重新确认；旧成果不删除。自带连接检查不调用模型；第三方 probe 的行为由可信插件实现，不保证其没有网络或费用。

项目 → 更多制作工具 → 扩展制作。选择工具、用途、镜头、时长或开始/结束画面，填写要求。可附保存的分镜文字、素材元数据；文件发送必须逐个勾选，最多4个。先查看本次调用内容，再确认本次费用和文件发送。生成文件回到原镜头候选区，必须人工检查并选用、保存分镜。分析不会直接修改工程。

“画分镜图”和“试拍视频”也提供扩展工具入口。没有启用扩展时给出设置引导。

## 兼容工具，不是自动识别任意软件

第三方服务必须有可信 DSH 插件或适配包装器实现下列协议。已有任意名字的 DSH 工具、网页地址或工作流文件不会自动成为媒体生成器。密钥由其服务或插件持有，不通过浏览器传入任务。不能声称一个统一协议已经验证所有厂商。

名字为 cutdirector_adapter_ 前缀，每个版本独立登记工具名。实际规范化 ToolDefinition 参考 examples/dsh-cutdirector-report。Host 使用 DSH 已解析工具集，并核对工具定义没有在调用前被替换。

### manifest / probe

- action=manifest：返回 registry.cjs 接受的 schemaVersion=1、hostRange=3 清单。
- action=probe：返回 available、message；检查失败保持不可启用。
- 图片/视频能力：image-generation / video-generation；权限至少 media-read，收费或模型额度需 paid-generation；若接受参考文件还需 media-upload。不得声明 draft-write。
- entryType=dsh-service；cost=free/model/paid；resume=poll/collect-only/manual 等必须与实现一致。
- inputSchema 和 outputSchema 是被真实校验的 JSON Schema 子集，具体见 adapter-sdk.cjs。可选择 additionalProperties=true 兼容协议字段扩展；不要用严格旧文字 schema 假装已支持媒体。
- 旧文字扩展仍收到 request、projectId、storyVersion、可选 story/assets，不强塞新媒体字段。

### execute

Host 只在 writer 成功持久化 running 后提交：

~~~json
{
  "action": "execute",
  "jobId": "稳定 UUID",
  "input": {
    "request": "这次批准的要求",
    "projectId": "工程 UUID",
    "storyVersion": 3,
    "capability": "image-generation",
    "shotId": "镜头 UUID",
    "shot": { "action": "镜头说明" },
    "ratio": "9:16",
    "frame": "start",
    "references": []
  },
  "workspace": {
    "root": "本次任务目录",
    "inputDir": "只含已选参考的复制文件",
    "outputDir": "本次产物目录",
    "references": []
  }
}
~~~

视频把 frame 换为 seconds（1–30整数），每次任务1份媒体产物。模型选择（若适用）固定为 model.provider / model.id。文件 references 由 writer 从本工程媒体库核对摘要后复制，Host 给插件的 workspace.references 才包含本次副本路径；浏览器不能指定源路径或产物目录。不能以元数据勾选替代文件上传授权。

立即完成的生成结果：

~~~json
{
  "state": "completed",
  "text": "这次图片已完成，请检查",
  "artifacts": [{ "file": "result.png", "kind": "image", "sha256": "可选 SHA256" }]
}
~~~

file 必须为 outputDir 下的单一文件名；禁止绝对路径、父级跳转、子目录、ADS、设备名、符号链接或路径重定向。图片只接受 PNG/JPEG，视频只接受 MP4/MOV，真实解码检查沿用媒体入口；单文件上限128MB，图片还受16MB入口上限，生成视频不超过35秒。检查真实长宽、图片画幅与分镜相符。文件绝不从模型回复中的任意路径或网址自动下载。

文字结果为 text 字符串（最多12000字符）。所有结果显示为文本，不能执行命令、HTML或提升权限。

### 远端异步任务

resume=poll 的适配器初次提交可以返回：

~~~json
{"state":"submitted","externalId":"供应商稳定任务号","text":"已提交，稍后查看结果"}
~~~

writer 保存 queued 和任务号。用户点击“查看处理结果”，Host 发送 action=status、原 externalId、同一冻结 input/workspace/jobId。适配器必须只查询这个已提交任务，不能再次 POST 生成请求。未完成时继续返回 submitted 和同一任务号，完成时返回本地文件描述。

status 需要将已完成媒体保存进原 outputDir。链接下载、域名校验、凭据、远端取消和供应商格式适配由该插件负责；CUTDIRECTOR 不接收任意下载 URL 代替文件。

### 崩溃、重复请求与产物恢复

- 准备任务有稳定 commandId；不同工程/输入不能复用。
- 审批绑定分镜版本、完整输入摘要、插件版本摘要，15分钟有效。确认时复核开关、付费同意及文件发送同意。
- 重复审批不重复派发；运行中切换版本不偷偷改路由。
- running 在重启后变 unknown；不会自动重新生成。
- checking 重启回 queued，只能查原远端任务。
- 收到合法文件描述先持久化 collecting；接收失败变 collect_failed。继续取回只读已有文件，不调用生成器；版本变更也不会导致重发。
- 每份产物用稳定 extension-任务ID-序号入库命令，保留工程、镜头、分镜版本、frame 来源；不进入其他镜头的候选区。
- 老版本候选保留，选用时走已有旧版本确认。生成不会自动替换分镜或更新偏好。
- “停止等待”中止自有等待，已交给供应商的任务可能继续收费；不宣称成功取消外部生成。

DSH 插件在 DSH 进程中拥有其自身权限。这里只约束 CUTDIRECTOR 的审批、派发、输入和产物采用，不是恶意插件的操作系统沙箱。安装可信插件是前提。

## DSH 原生只读分析

自带 cutdirector_adapter_native_dsh_analysis 通过本机实际 DSH agents.create 接口建立独立会话，不继承 CUTDIRECTOR 聊天全文。用户单独选本次 DSH 模型，单独授权本次证据。

创建时 tools.restrict(allow=[]) 拒绝所有继承工具，仅登记本次证据读取工具；单调 guard 核对 Agent 身份与工具名。无 shell、网络、工程写入、偏好审批、生成或再委派工具。最多3模型步、6次证据读取、12000字符结果，90秒控制预算，取消或退出释放句柄。返回建议及冻结证据摘要，不代替用户采用结果。

无费用检查创建无输入会话，核对工具目录只有1项，实际尝试全局工具被拒绝，再释放会话；没有 followup，不调用模型。当前真实 Desktop 检查通过。普通导演聊天仍使用 CUTDIRECTOR 自有循环，不创建原生聊天。

## Codex 原生出图

自带 cutdirector_adapter_native_codex_image 不使用只交回文字的 DSH Codex 提供者。它自动发现本机 Codex CLI，以本机已有登录启动 App Server 标准输入输出协议；只收原生 imageGeneration 完成事件的图片数据/受限生成缓存文件，不从助手文字里猜路径。记录本次任务，最多接受1份产物，不自动重试。

每次执行前用自有标记文件检查命名权限：任务目录可读、outputs可写、其他目录不可读写、命令网络关闭。关闭 shell、外接 MCP、应用和插件，拒绝所有追加工具/授权请求。会话 ephemeral，approvalPolicy=never，配置必须返回预期权限名。读取图像输入只使用已批准副本。平台不支持严格范围时关闭该能力，不改成完整访问。
