# CUTDIRECTOR 前端重设计
参考 https://github.com/woniuniuniu/dsh-media-desk ，固定研究提交 fc237f3388d048f51c3145cfd411dbb80ba2b388。使用用户指定的 design-taste-frontend 与 impeccable 技能；前端保持原生 JavaScript/CSS/HTML，无新框架依赖。

## 页面变化
- 工作台：紧凑浮动导航、真实灵感空间、单句记录、来源链接、可收起创作助手。
- 灵感：画布/信息流、筛选/搜索、阻尼平移缩放、懒加载真实附件图。小窗口默认可阅读的信息流。
- 灵感详情：左侧自有导演会话，右侧想法、补充、附件来源和项目引用。新对话与历史续接保留。
- 作品：真实项目卡，新建/导入入口；左侧导演、右侧制作稿面。主题与镜头先展示，编辑项按需展开。
- 制作工具：常用步骤为主要入口，其余全部保留在更多制作工具；镜头详情以弹窗查看。
- 对话：用户/导演消息分离，固定输入区，模型可见，可展开上下文和外发选项，停止和提案授权沿用原接口。
- 设置：对话模型、图片视频、剪映、方法、扩展工具、关于六类。旧工程入口保留。
- 任务、已有素材、图片视频制作、检查、交付和旧工程共用新的控件与布局系统。
- 动效：共享页面转场、导航指示块、内容进入、卡片布局、面板和弹窗进出；主题与降低动态效果均支持。
