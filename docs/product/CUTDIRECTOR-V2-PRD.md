## 1 产品定义

CUTDIRECTOR 是面向中文创作者的剪辑导演。用户说清想得到什么，Agent 自己看素材、听内容、挑重点、剪出一版。用户看完可以用自然语言改，也可以直接接手。主要服务两类人。

- 不会剪辑的人。能说「这段太长了，保留价格和怎么用，剪成半分钟」，不用先学术语和时间线。
- 会一些剪辑但想省时间的人。能把挑片段、去停顿、第一版节奏、字幕和粗剪交给 Agent，自己只做取舍和审片。

V2 以 **25 分钟以内的成片**为交付边界。源素材可以长于目标成片，长素材按段处理并显示进度。优先覆盖中文口播、介绍和轻度教程，再扩展卡点、多素材混剪和 Vlog。专业调色、多机位长片、复杂特效、云端协同、自动抓取第三方素材和自动发布均安排在本版边界之外。

## 2 已定决策与当前差距

| 主题 | V2 决策 |
| --- | --- |
| 两个入口 | 保留 Windows 一键启动的独立工作台和 DSH 侧栏嵌套工作台。两端共用界面、CUTDIRECTOR 会话、工程、草稿、任务和执行权限。 |
| Agent 所属 | CUTDIRECTOR 的 Loop 管理对话、剪辑策略、工具和授权。DSH 提供宿主、模型目录和单次推理，另有可选的原生 Agent 只读委派。 |
| 用户怎么授权 | 指令明确时自动分析并剪出独立草稿，生成预览无需逐刀确认。「采用草稿」才写入工程；「导出草稿」直接从该草稿渲染。现有「仅出方案」入口继续可用。 |
| 素材与模型 | 视频、音频、参考片和关键帧默认在本机处理。远程文本模型只接收任务需要的文字证据。发送原始音视频、关键帧或其他非文字素材须单独获得授权。 |
| 学习方式 | 通过导演策略、真实样片、审片反馈和用户显式保存的偏好持续改进。模型来源继续可换。 |
| 产品节奏 | 首次可用版同时交付易懂对话和中文口播草稿。卡点、参考视频和联网风格学习进入后续验收批次。 |

## 3 核心使用流程

| 步骤 | 用户看到或做什么 | Agent 怎么做 |
| --- | --- | --- |
| 1. 打开工程 | 独立版双击打开，或从 DSH 侧栏进入。打开视频后直接跟导演说话。 | 还原该工程最近打开的对话和草稿，显示当前选中的素材、目标和必须保留内容。DSH 入口优先显示其可用模型。 |
| 2. 描述目标 | 「把这 60 秒剪到 30 秒，价格一定保留。」 | 识别目标、限制和需保护内容。有明确目标时开始分析。只有关键取舍无法判断时才追问。 |
| 3. 等草稿 | 看到「正在听视频」「正在挑重点」「正在生成预览」，可以取消或稍后回来。 | 读取真实语音、时间和素材证据，按完整意思保留重点，形成可追溯的选段清单并渲染草稿。 |
| 4. 看结果并继续改 | 直接播放。可以点「加回这一句」，或说「改到 40 秒，开头自然一点」。 | 从指定草稿继续，明确这次改了什么。原来的草稿仍可打开比较。 |
| 5. 采用或导出 | 点「采用草稿」「导出草稿」，或回到历史草稿。 | 采用时检查原工程是否发生变化，一次性提交。导出绑定所选草稿；已采用的改动可用工程撤销。 |

用户只想了解功能时，Agent 回答完就停下。「转写是什么」可以回答：「就是把视频里说的话变成文字。这样我能找到重点，也能帮你做字幕。」如果当前有视频且识别可用，可附「帮我识别」；如果识别尚未就绪，可提供真实可点的「安装本地语音识别」「导入现有字幕」。

## 4 功能需求与优先级

### P0 · 好用的对话和自动口播

| ID | 需求 | 产品验收 |
| --- | --- | --- |
| FR-01 | 两端统一工作台。视频与草稿和聊天并列，窄屏可以切换。模型设置继续可在图形界面完成。 | 两端使用同一工程后能看到同一批对话和草稿；独立版在 DSH 停止时能使用本地配置的模型。 |
| FR-02 | 项目内新建、切换、回看和继续对话。按时间展示用户问题、Agent 答复、真实进度、草稿和反馈。 | 刷新、重启、跨入口后能恢复；新对话从新目标开始；旧 M4 记录可回看。 |
| FR-03 | 普通话优先、给出可点击的下一步。技术详情默认收起。 | 解释问题首句回答原问题，普通视图无内部命令和生帧号；缺能力时展示能实际执行的下一步。 |
| FR-04 | 用户可见并可纠正的目标。显示当前素材、目标时长、必须保留项。 | 「改成 40 秒」只改时长；当次明确要求优先于已启用偏好；不同会话的临时目标相互隔离。 |
| FR-05 | 一键本地语音识别安装与识别，支持导入已有字幕。 | 有真实识别结果、精度标识和来源。无语音、识别失败或识别未装时，提示具体下一步。 |
| FR-06 | 语义粗剪。支持同一源视频保留多个时间区间，保护数字、名称、否定、适用条件和已纠正字幕。 | 60→30 秒标准样片产出 28–32 秒可播放草稿。人工标出的必保内容完整。超时且无法兼顾时给出保留内容优先的最短方案。 |
| FR-07 | 自动草稿、预览、局部改稿、采用、导出、撤销。 | 草稿生成与导出期间原工程版本一致；同一草稿采用重试只生效一次；版本冲突时保留草稿供查看并说明怎么继续。 |
| FR-08 | 分段后台分析、停止与恢复、成片检查。 | 进度来自真实步骤。取消后停止后续任务。断点可恢复；输出有文件检查、内容检查和仍需人工看的项目。 |
| FR-09 | 能确认和撤销的偏好。 | 用户明示「以后都保留价格条件」才进入长期偏好；普通删改可以形成待查看的案例；撤销后新任务不再使用。 |

### P1 · 基础卡点与上传参考视频

- **FR-10 音乐卡点。** 用户提供音乐和多段自己的画面。自动找音乐节拍，选择合适切点，在预览里提供「切得快一些」「节奏缓一点」。
- **FR-11 参考片分析。** 支持本地参考视频。先说明拟采用的节奏、镜头切换或字幕规律，再将规律应用到用户自己的素材。参考片与可用于成片的素材明确区分。视觉理解不可用时仍能输出从镜头边界和节拍实际测得的结果。
- **FR-12 从画面提修改。** 用户在预览暂停时点「改这里」，指令绑定当前草稿和时间点，例如「这里的字小一点」或「这段停久一点」。先支持已具备工具的修改类型。

### P2 · 轻混剪、Vlog 与搜索

- **FR-13 轻混剪。** 支持多素材筛选、按时间或主题组织、背景音乐与原声混合。首个 Vlog 模板覆盖开场、主体和收尾，预览后可修改顺序或恢复现场声。
- **FR-14 联网学习风格。** 用户明确要求找参考时，搜索公开文字案例，呈现来源与采用的剪辑原则。用户可以选用、调整或跳过。结果进入任务参考，素材通过用户上传或明确加入工程进入成片。
- **FR-15 风格可重复使用。** 将一个确认过的风格提炼成易懂的描述、节奏偏好、字幕习惯和声音规则。支持在新会话选择、取消应用和编辑。

## 5 质量和边界

- **说人话。** 能用「识别视频里说的话」解释的地方就优先用这句话。可展开技术详情保留诊断价值。默认一句结果加一个下一步，复杂取舍再展开说明。
- **解释可核对。** Agent 说明保留、删掉或采用的关键点，用户能点到原视频和成片的位置。系统只能报告实际完成的检查。没有视觉或听感检查时，显示具体的待看事项。
- **输出不超过 25:00。** 目标超过上限时提示拆成两条。用户要求保护的内容超过目标但仍在上限内时，可给出可播放的保留版并标明实际时长；超过上限时请求取舍。
- **原素材与草稿隔离。** 原始素材和已有工程始终可继续打开。草稿、任务和已采用版本都有来源。云端模型、公开搜索和第三方素材均受本次任务授权和来源记录约束。
- **对新手友好。** 默认保留剪辑意图、预览和修改按钮；时间线、调试和模型高级项可展开。键盘能到达发送、停止、播放、采用与导出。加载、出错、空白与取消状态都有真实反馈。

## 6 怎样算交付

1. **短口播。** 授权中文样片覆盖清晰口播、噪声、专名、数字、否定、限制条件和长停顿。标准样片达到 28–32 秒，人工确认重点、语义、接缝和字幕。
2. **长成片。** 用接近 25 分钟的成片验收完整渲染与解码，并实测分析分段、取消、恢复和继续改稿；用 25:01 验证上限拦截。
3. **工程与双入口。** 同一个工程从两种入口继续。草稿不覆盖已有工程；采用时处理冲突和重放；断开 DSH 后独立版仍可使用本地模型。保留现有上传、字幕、预览、导出、回退和打包回归。
4. **真实新手测试。** 至少 10 名非剪辑用户参与，至少 8 人无需旁人解释即可让 Agent 压缩一条口播并找到草稿。记录是否看懂下一步、澄清次数、找不到控件次数和返工次数。用相同素材与任务比对 M4、V2 和可用的 DSH/Codex 参考体验。70%–80% 的目标用这类可重跑任务衡量，当前文档给出的是目标。
5. **逐批发布。** P0 通过真实样片和新手任务后发布。P1 另验节拍、参考视频与定点修改；P2 另验多素材、混音、搜索来源与断网处理。具体任务卡、数据契约和开源项目选型以配套执行手册为准。
