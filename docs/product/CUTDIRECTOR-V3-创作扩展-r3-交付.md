## 本轮实现

1. 助手独立闲聊：右上角助手现在支持普通交流、新对话、搜索与重命名。普通聊天不会自动建立灵感或作品；用户可把消息保存为灵感、建立作品。上下文默认不附项目，可明确选择作品资料。模型复用当前 DSH 配置，运行中的模型固定。
2. 剧本模块：按作品、分集、场景存放剧本。动作、对白、旁白、内心独白、音效分别标记。支持导入文本/DOCX 原文、选择原文区间、编辑剧本、历史版本、导出与冲突保护。首屏有“先试 10 秒”路线。
3. 分镜与概念资料：按集保存分镜、角色、场景、道具、概念图；支持卡片与表格、拆分、合并、排序、来源定位。分镜和生成片段是独立记录，一份生成片段可覆盖多镜。导演提出结构化建议，用户选择采用，旧版本提案不可覆盖新版。
4. 关系画布：本地打包 React Flow，无 CDN。剧本、场景、分镜、概念资料共享同一套内容，节点位置及关系单独保存。支持拖动、连接、自动排布、缩放和内容查看。这不是恢复已移除的灵感无限画布，灵感继续只用整齐卡片。
5. 图片与视频服务 GUI：预设 OpenAI 兼容图片、方舟图片/视频、RunningHub、ComfyUI、HTTP、MCP HTTP、可信本地 MCP、DSH 工具及 Codex。支持添加、检查、修改、移除、导入导出。Key 由 Windows 当前用户 DPAPI 保护，设置响应和导出不回显 Key。
6. DIY 工具标准 v2：JSON Schema、工具身份/版本/许可/依赖/权限/输入输出/成本/任务生命周期，声明式参数及产物映射。提供示例和 SDK；不把任意可执行脚本当作 JSON 参数运行。本地程序需要用户明确声明信任，仍属于用户进程权限，不宣称获得操作系统级沙箱。
7. 异步任务：准备时冻结模型、连接版本、素材、方法和目标版本；明确授权后提交。持久化外部任务 ID，查询/收集不重新生成；重启后不盲目重试不确定任务。产物先成为候选，再由用户采用。
8. 新工作流支持：可连接用户自己账号下的 RunningHub API 工作流，或本机 ComfyUI API 工作流；支持有序图片/音频参考、参数检查、节点依赖检查及结果回收。H3 方案以此承载，未将作者没有明确许可的素材/提示词包重新分发，也没有自动替用户购买服务或安装大模型。
9. 画面与声音：保留主画面，支持叠加反应画面、对白/音效/配乐轨、音量/淡入淡出/关键点，传递给剪映草稿编译器。仅完成本地 handoff 契约检查，真实多轨剪映导出仍待用户试用。
10. 保留原视觉：浅色创作空间、墨色主按钮、整齐卡片、统一的抽屉/对话/导航过渡；支持减少动画设置。没有把设置页和工具开发术语放入普通用户首次创作入口。

## 直接使用

- 自由聊天：右上角“助手”，在“模型与上下文”中选择 DSH 模型。
- 短剧：“剧本”→“第一次做：先试 10 秒”或“创作完整一集”。
- 已有作品：从剧本列表进入，写剧本→拆分镜→角色与场景→制作素材。需要把这一集用于现有制作流程时点击明确的发布入口。
- 接入服务：“设置”→“图片与视频”。普通用户选择预设并填写地址、Key、模型；DIY 参数在高级区域。
- 开发工具：“设置”→“工具与能力”，下载标准与示例。详细协议见《创作扩展与工具接入-v2》。
