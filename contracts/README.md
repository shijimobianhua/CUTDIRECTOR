# Frozen v1 contract (M1-T1)

`project.cjs.validate` is the executable schema. IDs are stable ASCII strings matching `[A-Za-z][A-Za-z0-9_-]{0,95}`; IDs are never reassigned to different instances. All project time is integer frames at `outputSpec.fps={num,den}`; source timestamps retain `timeBase` and `originUs`. Intervals are half open; speed is 1. Source in/out use the project CFR grid, relative to the normalized media origin. Unsupported VFR/origin/rotation must be rejected until normalized with a recorded mapping.

The sole current document is `<data>/<projectId>/project.json`, owned exclusively by ProjectStore. Its envelope atomically contains `project` (FableCut-compatible media/clips plus extension fields), immutable `history` and `ledger`. There is no independently writable sidecar timeline. Native FableCut servers, MCP and UI must never use this data directory; this product does not launch or proxy them.

ProjectHead: projectId/schemaVersion/revision/name/outputSpec/requirements/nativeRef. Asset: media[].id/hash/path/source/durationUs/timeBase/originUs/streams. WorkingMedia: asset.workingMedia with id/hash/assetId/path/conversion/mapping. Segment: clips[].id/mediaId/track/inFrame/outFrame/startFrame/speed, with native in/start/duration derived. Track: id/segmentIds. Transcript: id/assetId/model/language/precision/words/missing/uncertain. Caption: id/segmentId/wordIds/sourceInFrame/sourceOutFrame/text/corrections; output times derived from segment position. Revision: revision/parent/command/actor/diff/snapshot. Artifact: id/type/projectId/revision/manifestHash/hash/path/status/producer. Feedback: id/projectId/revision/request/actualDiff/decision/preferenceConfirmed.

Commands: `{projectId,baseRevision,commandId,op,target,params,actor}`. Actor is required (`human` or `agent`). Operations: caption.correct, segment.trim, segment.reorder, revision.restore, asset.relocate, project.archive, feedback.add, batch. Batch is all or nothing. Target IDs must exist. Canonical SHA256 sorts object keys, preserves array order and includes every request field; unknown fields are rejected. Same commandId and digest returns the original result, including after restart; changed content returns COMMAND_ID_CONFLICT. A stale base returns REVISION_CONFLICT/currentRevision. Failures do not consume a commandId. Successful results carry affectedIds and before/after diff. Restore creates a new revision. Archive is reversible via restore; no media is deleted.

Errors: VALIDATION_ERROR, FPS_INVALID, TIME_INVALID, RANGE_INVALID, TARGET_NOT_FOUND, REVISION_CONFLICT, COMMAND_ID_CONFLICT, WRITER_LOCKED, MEDIA_MISSING, MEDIA_CHANGED, MEDIA_UNSUPPORTED, PROVIDER_NOT_READY, REQUEST_ID_CONFLICT, NOT_FOUND, FORBIDDEN. HTTP maps conflicts to 409, invalid input to 400, missing objects to 404, missing providers to 503. No force writes.

Persistence uses fsync of a complete temporary envelope then same-directory rename. Failed pre-rename writes retain the old envelope; leftovers are ignored. Filesystem/disk power-loss durability on Windows is not promised. A workspace lock rejects second writers; after an unclean exit the operator must verify the recorded owner is stopped before removing the lock. History snapshots are read-only and never native live documents.
